# Contributing to ViralKit

Thanks for helping improve ViralKit. Keep changes focused and preserve the behavior of the deployed Monad Testnet contract and existing wallet, checkout, and indexing integrations.

## Development setup

Use Node.js `20.18.3` or newer and Yarn `3.2.3`. Follow the local setup in [README.md](README.md), and keep credentials in ignored environment files.

## Before opening a change

- Describe the user-visible or operational problem the change solves.
- Keep contract behavior and deployed addresses unchanged unless the change has been separately reviewed and approved.
- Do not include private keys, seed phrases, access tokens, or local environment files.
- Run the relevant contract or frontend checks for code changes and describe the results.
- Update product documentation when routes, configuration, or integration behavior changes.

## Pull requests

Use a clear title, summarize the change, list the checks you ran, and call out any environment configuration required to review it. Include screenshots for visual changes when practical.
